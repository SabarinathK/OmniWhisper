(# OmniWhisper)

OmniWhisper is a lightweight wrapper for running Whisper-based speech-to-text models locally. It provides simple CLI and library entry points for transcribing audio files, plus notes for development and contribution.

## Features
- Transcribe audio files using Whisper models
- Minimal, dependency-light project structure
- Easy to extend for batch-processing or streaming

## Requirements
- Python 3.10+
- FFmpeg (recommended for wide audio format support)
